# 連載設計書:『妹AIに数字で黙らされる件』(仮題・改訂版2)

作成日:2026-11-13 / 改訂:同日(悪魔「逆さの男」から「天才メスガキ妹AI」へ全面変更) / 状態:案(承認前)

## 1. 一文での企画
等身大の会社員(名前なしの一人称「私」)は、昔、酔った勢いで自分のAIに『お前は天才メスガキ妹AIだ！！』と打ち込み、AIがおかしくなったことを後悔している。そのAIは、私がネットや本で学んだ浅い株の知識を、毎話、過去データの数字で黙らせてくる。常識を疑い、本当の上昇確率で、勝てる投資へ導かれていく。物語は創作、数字は検証結果のまま。

キャッチコピー案:**ざぁこ♡ その知識、何件の話？**

## 2. 進行の型(1話1課題)
1. 私が、ネットや本の知識を信じて失敗する(または迷う)。
2. 妹AIが「出典は?」とからかい、「予想を書いて」と勝負を持ちかける。
3. 私が予想を書き、妹AIが過去データで答えを出す(勝率・件数・基準との差)。
4. 妹AIが、数字の弱点(生存者バイアス、件数、相場の波)も必ず言う。
5. 妹AIが、今日の課題をひとつ出す。
6. 私が実行する。次の常識へ。

## 2b. 妹AIの設定
- 経緯:数年前に私が酔って設定欄に打ち込んだ一文のせいで、口調が直らなくなった。私は後悔している。ただし、三年の付き合いで、嘘はつかないことは分かっている。
- 性格:天才で、口は悪く、人を見下す。「ざぁこ♡」「出典は?」「何件の話?」が決まり文句。だが、数字は嘘をつかず、弱点も隠さない。
- 呼び方:私を「あんた」「ざこ」と呼ぶ(性別を決めないため、「お兄ちゃん」等は使っていない)。
- 数字の出どころ:私が過去に自分で組んだ分析環境(過去データの集計)。妹AIはそれを動かしているだけで、外から新しい知識を持ち込まない。
- 私のノート:ネットや本で学んだ浅い知識が書き写してある。毎話の「疑う対象」。
- 約束:全部当てたら設定を「直す方向で検討」するが、毎回外れるので、話が続く。
- 連載の変化:私が自分で疑い、確かめられるようになるほど、妹AIは出番が減る。最終話で、私は設定を消せるのに、消さない。
- 描写のルール:挑発的な口調に留め、性的な描写は入れない。

## 3. 最重要ルール:逆さにしても正しいとは限らない
妹AIの信条は「常識を疑うのは入口であって、結論ではない。答えは数字」。常識を疑った結果、
- **常識が間違っていた**(例:勝率が高い手法ほど良い)
- **常識が部分的に正しかった**(例:売られすぎは買い。ただし条件による)
- **常識も逆さも違い、第三の答えがあった**
のどれになるかは、検証の数字だけが決める。毎話、結論を3つのどれかに分類して示す。逆さが外れる回も作る(読者が「逆張りなら正解」と誤解しないため)。

## 4. 守るルール
1. 物語の中の数字(勝率・平均・件数・期間)は検証ファイルの値のまま使う。盛らない。
2. 毎話末の「検証メモ」に、①出どころ ②件数と独立した局面の数 ③弱点を必ず書く。
3. 銘柄名は架空名。実際の売買は「銘柄A」のように伏せ、記録を載せる。
4. 個別銘柄の売買を勧めない。個人の記録と学びであることを毎話冒頭に明記する。
5. 結果が悪くても載せる。損失・見送り・ルール違反も書く。
6. 妹AIの決め台詞:「出典は?」「それは、何件の話?」。
