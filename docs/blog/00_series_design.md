# 連載設計書:『悪魔の統計学』(仮題)

作成日:2026-11-13 / 状態:案(承認前)

## 1. 一文での企画
等身大の会社員・水野湊(34歳)が、嘘をつかない悪魔マモンから「過去データの読み方」を教わりながら、少額の現物投資を実際に続ける。物語は創作、数字は検証結果のまま。

キャッチコピー案:**悪魔は嘘をつかない。ただし、数字は簡単に嘘をつく。**

## 2. 守るルール(ブログの信頼性のため)
1. 物語の中の数字(勝率・平均リターン・件数・期間)は、必ず検証ファイルの値をそのまま使う。盛らない。
2. 毎話の末尾に「検証メモ」を置き、①数字の出どころ(ファイル名・期間・対象)、②件数と独立した局面の数、③弱点・限界、を必ず書く。
3. 銘柄名は架空名にする(例:「ミナト精機」)。実際の売買は「銘柄A」のように伏せ、売買日・価格・結果を記録として載せる。
4. 「この銘柄を買え」とは書かない。個人の記録と学びであることを毎話の冒頭に明記する。
5. 悪魔の決め台詞は「それは、何件の話だ?」。件数を問う習慣を読者に持たせる。
6. 結果が悪くても載せる。損失・見送り・ルール違反もそのまま書く。

## 6. 湊の実践ルール(連載中の運用案)
- 現物のみ、1銘柄は資金の1/3以内(60万円なら最大3銘柄、100株単位)。
- 126営業日(約半年)保有、近い損切りなし。
- 市場環境の点検(警戒サイン)で「2個以上」の週は新規買いをしない。
- 候補が出ない週は見送る。見送りも記録する。

## 7. 要確認事項(公開前)
- 投資ブログの継続連載に伴う法的な位置づけ(投資助言業との関係、免責表記)は専門家に確認してください。私の側では確認できていません。
- 単元未満株(S株・かぶミニ等)で約定時刻が「月曜始値」と一致するかは、証券会社の公式ページで確認してください。
- 実際の売買記録を載せる場合、公開タイミング(売買直後は避けるか)と、保有銘柄の公開方法を決めてください。
