# 逆さまの悪魔 第1話 「上がる形」は、本当に上がるのか

> ※この物語はフィクションです。登場人物・銘柄・ネットの書き込みは架空で、個別銘柄の売買を勧めるものではありません。数字は筆者の検証結果です。

私のパソコンには、悪魔が棲んでいる。

三か月前、中古で買い替えたノートパソコンに、いつの間にか「それ」はいた。消そうとしても消えない。勝手にソフトが立ち上がり、画面が上下逆さまにひっくり返り、鏡文字の吹き出しが浮かぶ。吹き出しの中身は、いつも私への嘲笑だ。

「逆さまの悪魔」。私は、そう呼んでいる。

その夜、月末の経理の締めを終えて帰宅した私は、スマホで保有株を確認した。

「ミナト精機 -8.3%」。

先週、十万円で買った。理由は、投資掲示板の書き込みだ。

〈5日線が25日線を上抜けたら、上昇のサイン。ゴールデンクロスは裏切らない〉

溜め息をついてパソコンを開くと、見慣れない窓が勝手に立ち上がっていた。画面は上下逆さまで、鏡文字の吹き出しが揺れている。

〈ゴールデンクロス、か〉

〈クク。いい獲物が帰ってきたな〉

## 常識を、逆さまにする

「出てきて早々、人を笑うのはやめてくれ」

〈笑うさ。お前のノートを見ろ〉

机の上のノートが、勝手に開いていた。ネットや本で学んだ知識を書き写したものだ。「ゴールデンクロスは裏切らない」「新高値は強い」「売られすぎは落ちるナイフ」。どれも浅いと、自分でも薄々分かっている。

〈全部、受け売りだな。出典は〉

「……いろいろ」

〈いろいろ、か。傑作だ〉

鏡文字の吹き出しが、波打った。

〈逆さまにしてやろう。お前が信じるのは『上がる形が出れば上がる』。逆さまは『上がる形ほど上がらない』。ついでに『売られすぎの方が上がる』だ。どちらが本当か、調べてやる〉

「調べるって、データは」

〈お前は何も用意していない。だから、俺が調べる〉

画面の中でソフトが次々に立ち上がった。黒い窓に、白い文字が流れていく。株価の過去データを、ネットの向こうから勝手に引いているらしい。

〈予想を書け。調べている間に〉

〈お前の予想が外れるところを、見たいのでな〉

## 逆さまも、鵜呑みにするな

「じゃあ、売られすぎの方を買えばいいのか」

〈単純な男だ。そこが可愛い〉

悪魔が画面を切り替えた。

〈売られすぎのシグナルは、相場全体が崩れた週に、まとめて大量に出る。その後に相場が戻れば、どの銘柄も上がりやすい。だから高く見える〉

〈同じ週の全銘柄との差は、乖離で+1.6ポイント。ほかの売られすぎ系は+0.1〜0.7ポイント。上がる形系は-1.1〜+0.6ポイント。ほとんど差はない〉

「意味がないってことか」

〈そうは言っていない。52.5から59.7に動くなら、動いている。ただし、銘柄の力か、相場の波かは、分けて見ろ。俺は逆さまにするのが仕事だが、逆さまを結論にはしない。正しいかどうかは、数字が決める〉

〈それから、この数字には弱点がある。隠さずに言っておこう〉

悪魔が声を低くした。

〈一つ。今も上場している会社だけを過去にさかのぼって調べているので、つぶれた会社が抜けている。実際より、良く見える可能性がある〉

〈二つ。同じ週に出た事例は、ほとんど一つの出来事だ。乖離の1万5千件は、延べ915週にまたがるが、相場の局面としては、もっと少ない。「何万件」と言われたら、「それは、何件の話だ」と問え〉

私はノートの端に、書いた。**それは、何件の話だ?**

画面が、ふっと暗くなった。上下が元に戻り、見慣れたデスクトップが現れた。

ノートの「ゴールデンクロスは裏切らない」に、鉛筆で線を引いた。

スマホには、まだ赤い数字が出ている。八千円の損だ。だが、見え方が違った。これは、「上がる形」という物語に払った代金だった。

悪魔のソフトを、もう一度探した。アンインストールの項目は、やはり見つからない。

## 今日の学び

1. 何も条件を付けなくても、1か月後に上がる確率は約52.5%。シグナルの価値は、**この基準をどれだけ超えるか**で測る。
2. ネットで「上がる」と言われる形(ゴールデンクロス、新高値、200日線の上抜け)は、1か月後の上昇割合が50.9〜52.0%で、基準以下だった。
3. 売られすぎ系は54.1〜59.7%と基準より高いが、同じ週の全銘柄との差は小さい。数字を見たら「それは何件の話か」「相場全体の波ではないか」を問う。

**今日の結論の分類**:常識「上がる形が出たら上がる」→ **間違い(基準以下)**。「売られすぎの方が上がる」→ **一部は正しいが、差は小さい**。
