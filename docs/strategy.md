# 投資手法の言語化（2026-11-06 時点）

## 一文での定義
市場や業界ぐるみの売りに巻き込まれ、決算や固有の悪材料なしに売られすぎた銘柄を、決算の直前を避けて買い、
近い損切りを置かずに1〜3か月の反発を待つ。ただし、下げが信用不安の広がる危機型でないことを確かめ、
1銘柄あたりの金額は、2割の確率で起きる10%以上の下げに耐えられる大きさにとどめる。

## 検証で裏付けのある要素（TOPIX500相当、2008〜2026年、Yahoo Finance データ）
- 入口のシグナル：25日乖離≤-10%（3か月勝率62%、基準56%）。次点は RSI2<10、CCI20<-100 など売られすぎ系
- 地合い・業界ぐるみの下げ：業界内でシグナルの割合が高い 69〜70%、業種比の下げが-5%以内 67〜68%
- 避ける：決算直後の下げ 58%、決算での急落 56%、決算2週以内 54%、銘柄だけの大きな下げ 57〜58%
- 保有：1〜3か月、近い損切り・利確なし（+2%/-1.5%では勝率45%で利益が残らない）
- 優先：配当利回り2.6%以上 70〜71%

## 裏付けがない・弱い要素
- 「良い銘柄」の見極め（配当利回り以外は未検証）
- 業種予測による絞り込み（効果小、業種により逆効果）
- 銘柄ごとの過去勝率（将来に持続しない）
- 方向の予測（検証したモデルでは不可）

## 既知の弱点
- 金融危機型の下げでは効かない（2008年の勝率41%）
- 市場全体に対する上乗せは +1〜2pt 程度
- 3か月で-10%以下が約2割
