# 投資戦略の言語化（2026-11-07 改訂）

## 一文での定義
決算や固有の悪材料ではなく、業界ぐるみの売りで売られすぎた銘柄を、決算の前後を避けて翌週の寄り付きで買い、
近い損切り・利確を置かずに1〜3か月の反発を待つ。同じ業種に候補が複数あれば財務の強い銘柄を優先し、
財務が弱い銘柄や、利益の質に赤信号がある銘柄は避ける。

## 考え方
良い会社かどうかより「なぜ下げたか」が3か月後の結果を左右する。地合い・業界ぐるみの投げ売りに巻き込まれた銘柄は戻りやすく、
決算や固有の悪材料で下げた銘柄は戻りにくい。

## 手順
1. 週末：25日乖離≤-10% の銘柄を抽出する
2. 直前4週・直後2週に決算がある銘柄を外す
3. 業界ぐるみの下げ（同業種の30%以上にシグナル、または業種比20日の下げが-5%以内）だけを残す
4. 配当利回りが高い銘柄（実績2.6%以上）を優先する
5. （暫定）同じ業種に候補が複数あれば、財務の強い銘柄（ネットキャッシュ＞自己資本比率＞利払いの余力）を優先し、3つとも弱い銘柄は外す
6. （点検）利益の質に赤信号がある銘柄は、理由を個別に確かめ、説明がつかなければ見送る
7. 翌週月曜の寄り付きで成行買い。1銘柄の金額は、3か月で-10%以上下げる場合（約1〜2割の確率）に耐えられる大きさにする
8. 近い損切り・利確は置かず、1〜3か月で手仕舞う

## 根拠の強さ
### 確認済み（TOPIX500相当、2008〜2026年。数値は3か月後に上昇した割合）
| ルール | 根拠 |
|---|---|
| 25日乖離≤-10% | 62%（シグナルなしの基準 56%） |
| 決算の前後を避ける | 決算なし 64〜65% ／ 直前4週に決算あり 58% ／ 2週以内に決算 54% |
| 業界ぐるみの下げ | 決算なしと合わせて 70%（2023年以降 83〜87%） ／ 銘柄だけの大きな下げ 57〜58% |
| 高配当の優先 | 決算なしと合わせて 74%（2008・2020年を除いても 76%） |
| 寄り付きで成行 | 指値で待つより機会あたりの成績が良かった |
| 1〜3か月保有・近い損切り/利確なし | +2%/-1.5% では勝率45%で手数料後に利益が残らない。線は遠いほど成績が良かった |

### 暫定（2022年9月〜2026年7月、戦略の条件293件、独立した局面は約9回）
| ルール | 根拠 |
|---|---|
| 同じ業種の中で財務が強い銘柄を優先 | 業種内の強い3分の1／弱い3分の1：ネットキャッシュ 86.8%/73.4%、自己資本比率 83.0%/76.6%、利払いの余力 82.5%/75.5% |
| 財務が3つとも弱い銘柄を避ける | 戦略の条件で 53.8%（13件） |
- 財務は業種をまたいで比べない（単純比較では逆の結果になった）
- 効いたのは2024年8月が中心で、2025年4月は差がなかった

### 点検項目（検証していない。まれな大損を避ける目的）
利益の質の赤信号：
- 純利益は黒字なのに営業キャッシュフローが2期続けてマイナス
- 売掛金や在庫の伸びが、売上の伸びを大きく上回る
- 監査法人の交代、決算発表の延期、過去の決算の訂正などの開示

## 外した基準（今回の検証では有効性を確認できなかった）
- ROE（業種内上位・8%以上・前期比で悪化なし）：満たす銘柄 78.5% ／ 満たさない銘柄 84.8%
- 利益の質を絞り込み・優先順位に使うこと（営業CF/純利益、アクルーアル、FCF/総資産）：向きが場面でばらつき、業種内比較ではやや逆
- 業種予測（米国業種ETFのリードラグ等）による絞り込み：上乗せは小さく、業種によっては逆効果
- 銘柄ごとの過去の勝率：将来には続かない
- 指数や市場の方向の予測：検証したモデルは単純な予想に負けた
- 近い損切り・利確、終値より下の指値でのエントリー

## 既知の弱点（判定ルールは未確立）
- 金融危機型で下げが続く局面では効かない（2008年の勝率41%）。前半（2008〜2017年）は絞り込みによる上乗せがほとんどなかった
- 市場全体に対する上乗せは小さく、勝率の多くは市場全体の戻りによる
- 3か月で-10%以下になる確率は約1〜2割
- 財務の暫定ルールは、長い下げの局面を含まない短い期間でしか検証できていない

## 次に検証すべきこと
1. 金融危機型の下げを見分ける方法（社債価格の悪化の継続、VIX高止まりの期間、市場の下げの継続週数など）
2. 2008年を含む長期の財務データ（EDINET等）で、財務の暫定ルールを確かめる
3. 2026年11月以降の判定と結果を毎週記録し、実際の成績で確かめる
