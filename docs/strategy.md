# 投資戦略の言語化（2026-11-07 改訂：点検項目を具体化）

## 一文での定義
決算や固有の悪材料ではなく、業界ぐるみの売りで売られすぎた銘柄を、決算の前後を避けて翌週の寄り付きで買い、
近い損切り・利確を置かずに1〜3か月の反発を待つ。候補の中では、期待が控えめな銘柄（高配当、過去1年に上がりすぎていない）と
財務の強い銘柄を優先し、財務が弱い銘柄、利益の質に赤信号がある銘柄、直近の決算で大きなサプライズや大きな株価反応があった銘柄は、
下げの理由を確かめてから判断する。

## 考え方
良い会社かどうかより「なぜ下げたか」と「どれだけ期待が株価に入っていたか」が結果を左右する。
- 地合い・業界ぐるみの投げ売りに巻き込まれた銘柄は戻りやすく、決算や固有の悪材料で下げた銘柄は戻りにくい
- 過去1年に大きく買われて期待が積み上がっていた銘柄は、地合いの下げが期待の見直しの始まりになり、戻りが弱い
- 業績が予想より良かったか悪かったかは、ほとんど関係ない。直近の決算で大きなニュース（大きなサプライズ・大きな株価反応）があった銘柄は、
  上下どちらの向きでもやや戻りにくく、決算に静かだった銘柄が最も戻りやすい

## 手順
1. 週末：25日乖離≤-10% の銘柄を抽出する
2. 直前4週・直後2週に決算がある銘柄を外す
3. 業界ぐるみの下げ（同業種の30%以上にシグナル、または業種比20日の下げが-5%以内）だけを残す
4. 配当利回りが高い銘柄（実績2.6%以上）を優先する
5. 過去1年（直近1か月を除く）に業種より大きく上がっていた銘柄の優先度を下げる。目安は業種比+60%超、または1年で株価2倍以上
6. （暫定）同じ業種に候補が複数あれば、財務の強い銘柄（ネットキャッシュ＞自己資本比率＞利払いの余力）を優先し、3つとも弱い銘柄は外す
7. （点検）下の「点検項目の詳細」の点検1〜4を行い、判定表に従って進める／見送る
8. 翌週月曜の寄り付きで成行買い。1銘柄の金額は、3か月で-10%以上下げる場合（約1〜2割の確率）に耐えられる大きさにする
9. 近い損切り・利確は置かず、1〜3か月で手仕舞う

## 点検項目の詳細
閾値のうち、点検2・3はデータの集計に基づく。点検1・4の閾値は検証しておらず、意見による目安。

### 点検1：下げの理由（全候補で必ず行う）
| 確認すること | どこで見るか | 赤信号 |
|---|---|---|
| 直近4週間の適時開示 | TDnet、会社のIR、株探の開示一覧 | 業績・配当の下方修正、公募増資・新株予約権（MSワラント等）、不祥事・事故・行政処分、大型訴訟、主要取引先の喪失、大株主の売り出し |
| 直近4週間のニュース | 株探・日経などで銘柄名を検索 | その会社だけを名指しした悪材料（製品の不具合、受注の取り消し、格下げなど） |
| 同業他社も同じように下げたか | 業種比20日（手順3の数値）、同業2〜3社の株価 | その銘柄だけが業種より10%以上多く下げている |
| 指数・需給のイベント | 指数の銘柄入れ替えの発表、信用残 | 指数からの除外、信用買い残の急増（前月比+50%以上が目安） |
- 判定：赤信号がなく、下げが業種・市場の動きで説明できれば「説明がつく」

### 点検2：直近の決算のサプライズと株価反応
| 指標 | 定義 | 赤信号 |
|---|---|---|
| EPSサプライズ | 直近の四半期決算のEPS実績 ÷ アナリスト予想 − 1（Yahoo等の「EPS予想・実績」） | ±20%超 |
| 決算への株価反応 | 発表前日の終値 → 発表2営業日後の終値の騰落率 − 同じ期間の TOPIX（または日経平均）の騰落率 | ±10%超 |
赤信号があるときに確かめること：
- サプライズの原因が一過性か本業か（為替差損益、特別損益、資産売却、税金の調整など一過性のものか。売上・営業利益・受注が動いたのか）
- 同時に出た通期の会社予想が、上方修正／据え置き／下方修正のどれか
- 決算後に急騰していた場合、今回の下げはその上昇分を返している途中か（決算前の株価と比べる）
判定：
- 原因が一過性で、通期の会社予想が据え置き以上 → 進める
- 本業の悪化、または通期の会社予想の下方修正 → 見送る（手順2の「決算での下げ」と同じ扱い）
- 上振れで急騰した後の下げ → 手順5（上がりすぎ）と同じく優先度を下げる

### 点検3：上がりすぎ × 直近の決算が下振れ
- 条件：業種比1年の上昇率 +60%超（または株価が1年で2倍以上）、かつ直近のEPSサプライズがマイナス
- 判定：原則見送る（戦略の条件で3か月勝率 56.0%、25件。それ以外は 70〜71%）
- 例外：下振れの原因が一過性で、通期の会社予想が据え置き以上、かつ業種全体も同じように下げている場合のみ、優先度を最下位にして進めてよい

### 点検4：利益の質の赤信号（直近2期の決算短信・有価証券報告書で確認）
| 赤信号 | 具体的な目安 |
|---|---|
| 利益は出ているのに現金が入っていない | 純利益が黒字なのに、営業キャッシュフローが2期続けてマイナス |
| 売掛金がふくらんでいる | 売掛金（売上債権）の前年比の伸びが、売上の前年比の伸びより20ポイント以上大きい |
| 在庫がふくらんでいる | 棚卸資産の前年比の伸びが、売上の前年比の伸びより20ポイント以上大きい |
| 会計への疑い | 監査法人の交代（「公認会計士等の異動」の開示）、決算発表の延期、決算短信・有価証券報告書の訂正、特別調査委員会の設置、「継続企業の前提に関する注記」 |
判定：
- 会計への疑いが1つでもある → 見送る
- 売掛金・在庫・営業キャッシュフローの赤信号 → 会社の説明（決算説明資料の大型受注、先行仕入れ、季節要因など）で説明がつけば進める。つかなければ見送る

### 判定表（まとめ）
| 状況 | 判断 |
|---|---|
| 点検1〜4のどれにも赤信号なし | 進める（手順4〜6の優先順位どおり） |
| 赤信号はあるが、一過性・業種全体の動き・会社の説明で説明がつく | 進める（優先度は1段下げる） |
| 本業の悪化、通期の会社予想の下方修正、会計への疑い | 見送る |
| 上がりすぎ × 直近の決算が下振れ | 原則見送る（点検3の例外のみ可） |
| 判断がつかない | 見送る（候補は毎週出るため、無理に入らない） |

## 根拠の強さ
### 確認済み（TOPIX500相当、2008〜2026年。数値は3か月後に上昇した割合）
| ルール | 根拠 |
|---|---|
| 25日乖離≤-10% | 62%（シグナルなしの基準 56%） |
| 決算の前後を避ける | 決算なし 64〜65% ／ 直前4週に決算あり 58% ／ 2週以内に決算 54% |
| 業界ぐるみの下げ | 決算なしと合わせて 70%（2023年以降 83〜87%） ／ 銘柄だけの大きな下げ 57〜58% |
| 高配当の優先 | 決算なしと合わせて 74%（2008・2020年を除いても 76%） |
| 寄り付きで成行 | 指値で待つより機会あたりの成績が良かった |
| 1〜3か月保有・近い損切り/利確なし | +2%/-1.5% では勝率45%で手数料後に利益が残らない。線は遠いほど成績が良かった |
| 過去1年に上がりすぎていた銘柄の優先度を下げる | 同じ週の候補の中で、業種比1年の上昇率の上位20%と下位20%の差：1か月後 -4.8pt（t -2.3）、3か月後 -6.7pt（t -3.1）、6か月後 -10.9pt（t -4.7）。4つの時期すべてでマイナス。業種比+60%超は3か月勝率55.9%（基準62.4%）、-10%以下26% |
- 上がりすぎの判定は、同じ週の候補同士、または業種比で行う。全期間をまとめて比べると、時期の違い（2008年の危機）が混ざり逆に見える
- 過去3か月だけの急騰や、1年の安値から高値までの上昇幅では差がなかった

### 暫定（2022年9月〜2026年7月、戦略の条件293件、独立した局面は約9回）
| ルール | 根拠 |
|---|---|
| 同じ業種の中で財務が強い銘柄を優先 | 業種内の強い3分の1／弱い3分の1：ネットキャッシュ 86.8%/73.4%、自己資本比率 83.0%/76.6%、利払いの余力 82.5%/75.5% |
| 財務が3つとも弱い銘柄を避ける | 戦略の条件で 53.8%（13件） |
- 財務は業種をまたいで比べない（単純比較では逆の結果になった）
- 効いたのは2024年8月が中心で、2025年4月は差がなかった

### 点検項目（統計の効果は小さい、または検証していない。まれな大損を避ける目的）
| 項目 | 根拠 |
|---|---|
| 直近の決算で大きなサプライズ・大きな株価反応 | 2008〜2026年、10,360件。サプライズ大幅上振れ（+20%超）59.0%、大幅下振れ（-20%以下）61.7%、±20%以内 63〜63.4%。株価反応 ±3%以内 64.0%、-10%以下 57.6%、+10%超 59.8%（全シグナル）。戦略の条件では差は2〜5pt |
| 上がりすぎ × 直近の決算が下振れ | 戦略の条件で 56.0%（25件のみ）。それ以外は 70〜71% |
| 利益の質の赤信号 | 検証していない：純利益は黒字なのに営業キャッシュフローが2期続けてマイナス／売掛金や在庫の伸びが売上の伸びを大きく上回る／監査法人の交代・決算発表の延期・過去の決算の訂正 |

## 外した基準（今回の検証では有効性を確認できなかった）
- ROE（業種内上位・8%以上・前期比で悪化なし）：満たす銘柄 78.5% ／ 満たさない銘柄 84.8%
- 利益の質を絞り込み・優先順位に使うこと（営業CF/純利益、アクルーアル、FCF/総資産）：向きが場面でばらつき、業種内比較ではやや逆
- 成長性（売上・営業利益・純利益の前年比）：業種内比較では差がほぼない。単純比較で増収増益が弱く見えたのは、過去1年の株価の上がりすぎによる
- 業績のサプライズの向き（予想を上回ったか下回ったか、直近4回の上振れ回数）：一貫した差なし。同じ週の中の比較で、直近2回の平均が高い方が6か月後にやや良い（+4.5pt、t 2.5）が、多重検定の目安に届かない
- 業種予測（米国業種ETFのリードラグ等）による絞り込み：上乗せは小さく、業種によっては逆効果
- 銘柄ごとの過去の勝率：将来には続かない
- 指数や市場の方向の予測：検証したモデルは単純な予想に負けた
- 近い損切り・利確、終値より下の指値でのエントリー

## 既知の弱点（判定ルールは未確立）
- 金融危機型で下げが続く局面では効かない（2008年の勝率41%）。前半（2008〜2017年）は絞り込みによる上乗せがほとんどなかった
- 市場全体に対する上乗せは小さく、勝率の多くは市場全体の戻りによる
- 3か月で-10%以下になる確率は約1〜2割
- 財務の暫定ルールは、長い下げの局面を含まない短い期間でしか検証できていない

## 次に検証すべきこと
1. 金融危機型の下げを見分ける方法（社債価格の悪化の継続、VIX高止まりの期間、市場の下げの継続週数など）
2. 会社の業績予想の修正・アナリスト予想の修正の推移（業績の向きの本来の指標。過去の時点の値の入手が課題）
3. 2008年を含む長期の財務データ（EDINET等）で、財務の暫定ルールを確かめる
4. 2026年11月以降の判定と結果を毎週記録し、実際の成績で確かめる
