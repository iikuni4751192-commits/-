# 投資手法の言語化（2026-11-06 改訂：有効性を確認できなかった基準を除外）

## 一文での定義
決算や固有の悪材料ではなく、業界ぐるみの売りで売られすぎた銘柄を、決算の前後を避けて翌週の寄り付きで買い、
近い損切り・利確を置かずに1〜3か月の反発を待つ。

## ルール（検証で裏付けがあったもののみ）
| 段階 | ルール | 根拠（3か月後に上昇した割合。TOPIX500相当・2008〜2026年） |
|---|---|---|
| 入口 | 週末の終値で 25日乖離≤-10% | 62%（シグナルなしの基準 56%） |
| 絞り込み1 | 決算を避ける：直前4週・直後2週に決算がない | 決算なし 64〜65% ／ 直前4週に決算あり 58% ／ 2週以内に決算 54% |
| 絞り込み2 | 業界ぐるみの下げ：同業種の30%以上にシグナル、または業種比20日の下げが-5%以内 | 決算なしと合わせて 70%（2023年以降 83〜87%） ／ 銘柄だけの大きな下げ 57〜58% |
| 優先 | 配当利回りが高い（実績2.6%以上） | 決算なしと合わせて 74%（2008・2020年を除いても 76%） |
| 買い方 | 翌週月曜の寄り付きで成行 | 指値で待つより機会あたりの成績が良かった |
| 保有 | 1〜3か月、近い損切り・利確は置かない | +2%/-1.5% では勝率45%で手数料後に利益が残らない。線は遠いほど成績が良かった |

## 外した基準（今回の検証では有効性を確認できなかった）
- ROE（業種内上位・8%以上・前期比で悪化なし）：条件を満たす銘柄 78.5% ／ 満たさない銘柄 84.8%（2023〜2026年、局面5〜7回）
- 業種予測（米国業種ETFのリードラグ等）による絞り込み：上乗せは小さく、業種によっては逆効果
- 銘柄ごとの過去の勝率：将来には続かない（前半と後半の相関 0.03）
- 指数や市場の方向の予測：検証したモデルは単純な予想に負けた
- 近い損切り・利確、終値より下の指値でのエントリー

## 既知の弱点（判定ルールは未確立）
- 金融危機型で下げが続く局面では効かない（2008年の勝率41%）。前半（2008〜2017年）では、絞り込みによる上乗せがほとんどなかった
- 市場全体に対する上乗せは小さく、勝率の多くは市場全体の戻りによる
- 3か月で-10%以下になる確率は約2割（絞り込み後は5〜11%）。1銘柄あたりの金額はこれに耐えられる大きさにする
