## 検証ログ

### 原因1：損切り幅（2026-10-12）
開発=2010-01〜2024-08、W=2024-09-17〜2026-10-09（騰落レシオあり）

| 案 | 開発 年率 / PF / 取引 | W 年率 / PF / 取引 |
|---|---|---|
| 現行 | 1.78% / 1.92 / 91 | −3.35% / 0.30 / 17 |
| ① 損切り幅下限 1→2ATR | −0.03% / 0.90 / 18 | −0.24% / — / 1 |
| ② Setup B 損切り 水準−1→−2ATR | 0.57% / 1.33 / 90 | 0.38% / 1.04 / 15 |
| ①+② | 0.72% / 1.74 / 63 | 0.50% / 1.13 / 12 |

判定: いずれも採用条件（両期間で悪化しない）を満たさない。利用者判断で ①+② を採用し、
ルール表（1_指標設定 C23、3_エントリー A4・B4）と strategies/rulebook_1321.yaml に反映。
以降の原因2〜6の検証は ①+② を基準（ベースライン）とする。

### 原因2：窓開けによる損切りの不利約定（2026-10-12）
基準は原因1修正後（①+②）。`python analysis/compare_variants.py`

| 案 | 開発 年率 / PF / 取引 / 最大DD | W 年率 / PF / 取引 / 最大DD |
|---|---|---|
| 基準（ザラ場逆指値） | 0.72% / 1.74 / 63 / −4.0% | 0.50% / 1.13 / 12 / −3.3% |
| 案B 終値で損切り判定→翌寄り決済 | 0.82% / 1.87 / 63 / −3.4% | 1.34% / 1.64 / 10 / −3.7% |
| 参考 案B＋緊急逆指値（−1ATR） | 0.75% / 1.75 / 63 / −4.1% | 1.34% / 1.64 / 10 / −3.7% |

判定: 案B は両期間で年率・PFが改善し採用条件を満たす（W の最大DDは −3.3%→−3.7% とわずかに悪化）。
注意: 損切り1回あたりの損失は縮小していない（W の損切り1件 −1.78R、開発の最悪 −1.52R）。改善の主因は
損切り回数の減少（開発 11→6件、W 3→1件）で、原因2そのもの（−1R超の損失）は解消していない。
ルール表（4_決済損切り X1・X2・X4、3_エントリー A4・C3）と strategies/rulebook_1321.yaml（stop_mode: close）に反映。

### 原因3：Setup A の MA25割れ決済（2026-10-12）
基準は原因2修正後（stop_mode: close）。`python analysis/compare_variants.py --cause 3`

| 案 | 開発 年率 / PF / 最大DD / A件数・A損益 | W 年率 / PF / 最大DD / A件数・A損益 |
|---|---|---|
| 基準（A も MA25割れ） | 0.82% / 1.87 / −3.4% / 14件・+81,129円 | 1.34% / 1.64 / −3.7% / 1件・−11,958円 |
| 案1 A は MA25−1ATR 割れ | 0.79% / 1.73 / −4.4% / 14件・+73,707円 | 1.34% / 1.64 / −3.7% / 1件・−11,958円 |
| 案2 A はスイング安値割れ（MA25割れなし） | 0.83% / 1.77 / −4.5% / 13件・+87,474円 | 1.53% / 1.85 / −3.3% / 1件・−2,793円 |

判定: 案1 は開発期間で悪化（不採用）。案2 は年率では両期間とも悪化せず採用条件をかろうじて満たすが、
開発期間の PF・最大DD は悪化し、差（14年で約1,300円）は誤差の範囲。原因1の修正（損切り幅2ATR以上）で
Setup A の取引が 14件/1件まで減っており、原因3の影響は修正前より小さくなっている。
→ 利用者判断で案2を採用。ルール表（4_決済損切り X6）と strategies/rulebook_1321.yaml（a_exit_mode: swing_low）に反映。
以降の検証は案2を基準とする。

### 原因4：相場にいる時間・量が少ない（2026-10-12）
基準は原因3修正後（a_exit_mode: swing_low）。`python analysis/compare_variants.py --cause 4`
（実質投資率＝全営業日平均の 建玉金額/資産。E5 は騰落レシオのある W 期間のみ作用）

| 案 | 開発 年率 / PF / 最大DD / 実質投資率 | W 年率 / PF / 最大DD / 実質投資率 |

| 基準 | 0.83% / 1.77 / −4.5% / 5.5% | 1.53% / 1.85 / −3.3% / 5.8% |

判定: 案1a は両期間で年率・PF・最大DDとも改善（採用条件を満たす）。案1b・1c は W で悪化（不採用。E5 は有効）。
案2 は年率が約2倍になるが最大DDもほぼ2倍で、年率/最大DD は開発 0.18→0.18、W 0.46→0.63。
優位性の改善ではなくリスク量の拡大であり、採否は許容できる損失の大きさで決める事項。
見送り条件を外しても保有日の割合はほぼ変わらず（30.0%→31.2%）、実質投資率が5〜6%と低いことが
買い持ちとの差の主因。
→ 利用者判断で 案1a＋案2 を採用。ルール表（2_環境認識 E8、5_資金管理 B5・C20）と
strategies/rulebook_1321.yaml（event_entry_block: false、risk_per_trade: 0.02）に反映。以降の検証はこれを基準とする。
